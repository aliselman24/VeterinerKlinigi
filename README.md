# Veteriner Kliniği Randevu ve Hasta Takip Sistemi

## Proje Hakkında

BSM 311 Web Programlama dersi kapsamında geliştirilen veteriner kliniği yönetim sistemidir.

## Planlanan Özellikler

- Klinik ve hizmet yönetimi
- Veteriner hekim yönetimi
- Evcil hayvan ve aşı takibi
- Randevu oluşturma ve çakışma kontrolü
- Rol bazlı yetkilendirme
- Admin paneli
- REST API
- MCP yapay zekâ entegrasyonu

## Kullanılacak Teknolojiler

- ASP.NET Core MVC (.NET 10)
- C#
- Entity Framework Core
- SQLite
- ASP.NET Core Identity
- Bootstrap 5
- REST API
- Model Context Protocol (MCP)

Geliştirme aşamasında.
